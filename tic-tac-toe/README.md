# ❌⭕ Tic-Tac-Toe CLI (Python)

A feature-rich Command Line Interface (CLI) Tic-Tac-Toe game built with Python using Object-Oriented Programming (OOP) principles. Features single-player vs. a smart AI opponent, local 2-player mode, persistent score tracking, and clean terminal rendering.

---

## ✨ Features

* **🕹️ Two Game Modes:**
  * **Single Player:** Play against an AI opponent that actively blocks winning moves and goes for victory.
  * **2 Players:** Local turn-based multiplayer.
* **🧼 Smooth Terminal View:** Automatically clears the terminal on each turn for a clean UI experience.
* **📊 Scoreboard Tracker:** Tracks total wins for Player X, Player O / AI, and Draws across multiple rounds.
* **🛡️ Input Guardrails:** Robust error protection against letters, out-of-bounds numbers, and taken spots without crashing.
* **🔄 Replay System:** Play continuous rounds seamlessly without restarting the application.

---
